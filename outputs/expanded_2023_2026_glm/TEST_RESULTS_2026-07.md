# Condition Diffusion 2026-07 测试报告

## 1. 实验概况

本次实验使用带有 48 维 GLM 条件信息的 Conditional Diffusion-TS 模型，对 2026 年 7 月的股票时间序列进行概率预测。

数据划分如下：

| 数据集 | 时间范围 |
|---|---|
| 训练集 | 2023-01-03 至 2026-05-29 |
| 验证集 | 2026-06-01 至 2026-06-30 |
| 测试集 | 2026-07-01 至 2026-07-31 |

每只股票独立构建时间序列，没有将不同股票首尾连接。最终平衡面板包含：

- 3,574 只股票；
- 866 个交易日；
- 3,095,084 个“日期—股票”键；
- 19 维 Scheme A 数值特征；
- 48 维 GLM 条件特征；
- 48 维 observed mask；
- 每个时间点合计 115 维。

模型输入过去 60 个交易日，预测未来 18 个交易日。测试集包含 6 个预测起点，每个起点覆盖 3,574 只股票，因此共有 21,444 个测试窗口。每个窗口生成 5 条概率预测轨迹。

## 2. 训练结果

- 训练设备：NVIDIA GeForce RTX 4070 Ti；
- 正式训练步数：45,000；
- 最佳检查点：第 35,000 步；
- 最佳验证 loss：0.0341708；
- 第 45,000 步验证 loss：0.035215。

正式测试使用验证集表现最好的 `checkpoint-best.pt`，而不是最后一步模型。

## 3. 核心测试指标

| 指标 | 模型结果 | Persistence 基线 |
|---|---:|---:|
| MAE | 0.174785 | 0.202136 |
| RMSE | 0.492555 | 0.555221 |
| CRPS | 0.143552 | — |
| 80% 区间覆盖率 PICP | 37.1946% | — |
| 80% 区间平均宽度 | 0.214312 | — |

相对于 persistence 基线，模型的 MAE 降低了 13.53%，RMSE 约降低 11.29%。这说明模型的点预测整体优于简单地将历史最后一个值延续到未来。

CRPS 同时评价预测分布的位置和离散程度，越小越好。本次 CRPS 为 0.143552。

需要重点注意的是，名义上的 80% 预测区间实际只覆盖了 37.19% 的真实值。模型生成的概率区间明显过窄，存在较严重的欠覆盖问题。因此，当前模型适合用于点预测实验，但不能直接把输出区间解释为已经校准的 80% 置信区间。

## 4. VWAP 涨跌方向结果

方向定义为未来 VWAP 相对于每个预测窗口起点的变化方向。

| 指标 | 结果 |
|---|---:|
| 方向准确率 | 67.7632% |
| 平衡准确率 | 68.5027% |
| 上涨召回率 | 92.9624% |
| 下跌召回率 | 44.0430% |
| 实际上涨比例 | 48.4882% |
| 预测上涨比例 | 73.9003% |
| 逐日涨跌准确率 | 58.6223% |

VWAP 方向混淆计数：

| 类型 | 数量 |
|---|---:|
| 预测上涨、实际上涨 | 173,110 |
| 预测下跌、实际下跌 | 87,129 |
| 预测上涨、实际下跌 | 110,698 |
| 预测下跌、实际上涨 | 13,105 |
| 有效方向样本 | 384,042 |
| 平局或零变化样本 | 1,950 |

模型对上涨的识别能力很强，但对下跌的召回率明显较低。模型预测上涨的比例达到 73.90%，而实际上涨比例只有 48.49%，说明存在较强的上涨预测偏置。因此，67.76% 的原始方向准确率必须与平衡准确率、下跌召回率和预测上涨比例一起解读。

对所有 19 个 Scheme A 特征汇总后：

- 相对预测起点的方向准确率为 62.07%；
- 相对预测起点的平衡准确率为 62.04%；
- 逐日方向准确率为 55.50%。

## 5. 原 Diffusion-TS 风格评估指标

为了与原 Diffusion-TS 仓库的评估方式保持一致，还计算了 MSE、相关性、判别、预测和 Context-FID 指标。

| 指标 | 结果 |
|---|---:|
| 单条生成轨迹原尺度 MSE | 0.280200 |
| Correlational score | 0.565064 |
| Discriminative score | 0.375752 ± 0.021544 |
| Predictive score | 0.0161166 ± 0.0000424 |
| Context-FID | 0.416047 ± 0.063726 |

其中 Discriminative、Predictive 和 Context-FID 均进行了 5 次重复实验。

这些指标通常越低越好。Discriminative score 距离理想值 0 仍较远，说明判别器仍能较容易地区分真实轨迹和生成轨迹；生成分布对真实时间序列分布的拟合还有提升空间。

原仓库风格的 MSE 使用第一条随机生成轨迹，而核心 MAE、RMSE 使用 5 条生成轨迹的均值，因此两套结果不能直接通过平方关系进行换算。

## 6. 逐特征误差概览

MAE 较小的特征包括：

| 特征 | MAE |
|---|---:|
| io_to_float_a_share | 0.002276 |
| delta_io_to_float_share | 0.005762 |
| est_num_diff | 0.026723 |
| growth | 0.033465 |
| swap_3m | 0.041753 |

MAE 较大的特征包括：

| 特征 | MAE |
|---|---:|
| volatility | 0.302180 |
| turnover_stdrate_3m | 0.337477 |
| ivr | 0.356164 |
| corr_close_turnover | 0.484128 |
| reverse_1m | 0.524385 |

不同特征的数值尺度不同，因此不能仅根据原尺度 MAE 判断哪个特征更容易预测。更严谨的逐特征比较还应结合标准化误差和各特征的实际波动范围。

## 7. 结论

本次带 48 维 GLM 条件的模型训练和测试均正常完成。主要结论如下：

1. 模型的 MAE 和 RMSE 均优于 persistence 基线，MAE 改善 13.53%；
2. VWAP 相对预测起点的方向准确率为 67.76%，但存在明显的上涨预测偏置；
3. 逐日 VWAP 涨跌准确率为 58.62%，低于相对预测起点的累计方向准确率；
4. 80% 预测区间实际覆盖率只有 37.19%，概率预测尚未得到良好校准；
5. 判别指标显示生成轨迹与真实轨迹的分布仍有明显差异；
6. 当前版本可以作为优于 persistence 的点预测基线，但在用于风险区间、下跌识别或仓位决策前，还需要进行概率校准和上涨偏置修正。

本报告只包含正式的 48 维 GLM 条件版本，不包含 GLM 消融或随机打乱条件实验。
